# Data Directory Structure

This directory holds all data used for training the Transformer model and generating features. 
The layout is designed to mirror the pipeline stages (Ingestion -> Separation -> Feature Extraction).

## Structure Overview

- **`raw/`**: Original legacy film files (e.g., `.mp4`, `.mkv`, `.wav`).
- **`processed/`**: Intermediate and final data ready for training.
  - **`audio/`**: Pre-processed, resampled (e.g., 44.1 kHz), and normalized `.wav` files.
  - **`stems/`**: Isolated instrument stems generated by the source separator (Demucs).
  - **`features/`**: Saved Constant-Q Transform (CQT) spectrograms (e.g., `.pt` PyTorch tensors) ready for the SED Transformer model.
- **`metadata/`**: Annotations, ground-truth labels (JSON/CSV), and data splits (train/val/test).

## Instructions for Training

1. **Place raw files**: Put all incoming film audio/video files in `data/raw/`.
2. **Pre-process**: Run the ingestion pipeline to extract, resample, and normalize audio. It will populate `data/processed/audio/`.
3. **Separate**: Run the source separation pipeline. This will take files from `data/processed/audio/` and create subdirectories in `data/processed/stems/` for each isolated track (e.g., vocals, drums, bass, other).
4. **Extract Features**: Run the feature extraction pipeline to convert the stems into CQT spectrograms. These will be saved in `data/processed/features/`.
5. **Train**: The model will load the CQT tensors directly from `data/processed/features/` and the labels from `data/metadata/`.
